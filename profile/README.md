### Core Servicing Capabilities & Updates

* **Automated 1-Click FMI Removal:** Automates local encrypted backup parsing internally, removing the legacy need to manually extract backups via 3uTools, iTunes, Elcomsoft, or local proxy servers to locate authentication tokens.
* **Backup Password Toggle:** Includes an integrated option to turn off an existing encrypted backup password using the previous password.

### Eligibility Criteria & Setup Workflow

Before registering a serial number or UDID on a server, the target iPhone or iPad must meet strict **Open Menu** conditions:

1. The device must boot normally to the Home Screen and have **iCloud Storage load** properly inside **Settings > [Apple ID] > iCloud**.
2. **Game Center** (or **Media & Purchases**) must be accessible and able to toggle off and back on without prompting for the Apple ID password.

1. **Install Official iTunes & Extract Tool:** Prerequisite driver setup.
Install **iTunes for Windows** using Apple's official standalone installer so `Apple Mobile Device USB Drivers` are properly registered. Extract the `HFZ Open Menu` archive to the root of your `C:\` drive (e.g., `C:\HFZ_OpenMenu\`).

*Verification:* Open Windows **Device Manager** (`devmgmt.msc`) and verify that connecting your iPhone displays `Apple Mobile Device USB Driver` under `Universal Serial Bus controllers` with no warning icons.


2. **Connect Device & Register UDID:** UDID/SN server registration.
Right-click `HFZ Open Menu FMI-OFF Tool.exe` and select **Run as Administrator**. Connect the unlocked iPhone via USB, tap **Trust This Computer** on the phone screen, and copy the device's **UDID / Serial Number** to register it through an authorized HFZ distributor (`hfztool.com`).

*Verification:* The tool interface recognizes the connected model, iOS version, and confirms server authorization status.


3. **Toggle Game Center & Execute FMI Off:** Token refresh & execution.
On the iPhone, open **Settings > Game Center**, toggle it **OFF** and back **ON**, then enable **Airplane Mode** and turn **Wi-Fi OFF** as prompted by the workflow. Click **OFF FMI** in the Windows tool and wait for the automated backup scan to send the unbind request.

*Verification:* Once the tool prints `Done`, verify the device's Serial Number/IMEI on an official FMI checker to confirm `Find My iPhone: OFF`.


4. **Perform Full DFU / iTunes Restore:** Final cleanup.
After server-side FMI status switches to `OFF`, erase all content or perform a full **DFU Restore** via iTunes/Finder to wipe the cached Apple ID from the local device.

*Verification:* The device activates cleanly during initial setup without asking for the previous Apple ID credentials.
